# Christiaan Swanepoel

Minimalist, highly performant creative portfolio website featuring an interactive Perlin noise flow field simulation.

Live at: [swantaan.github.io/portfolio/](https://swantaan.github.io/portfolio/)

## Build

- **Structure**: HTML5
- **Style**: CSS3 (Vanilla)
- **Physics**: Custom 3D Perlin Noise Canvas Engine
- **Assets**: Inline SVGs (No external image downloads)

## Development

Open `index.html` directly in the browser, or start a local server:

```bash
python -m http.server 8000
```
